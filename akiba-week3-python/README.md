## How to Run

Open a terminal in the `akiba-week3-python` folder and run any program with Python. For example:

```bash
python task_01_shopping_receipt.py
```

To run another task, replace `task_01_shopping_receipt.py` with the desired task file. The mini project is organized in the `mini_project` folder, with `main.py` as its entry point.
