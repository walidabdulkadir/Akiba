**Assignment title:** Object-Oriented Programming and Library Management System

## Project description

This assignment is organized into five question programs and a mini-project
scaffold for a library management system. The Python files are currently
placeholders; the examples and mini-project behavior still need to be
implemented.

## OOP concepts

The assignment is intended to demonstrate:

- Classes and objects
- Attributes and methods
- Encapsulation of related data and behavior
- Composition and collaboration between objects
- Organizing a program into modules

## Running the programs

From this directory, run an individual question with Python:

```powershell
python .\questions\question_1.py
```

Replace `question_1.py` with `question_2.py` through `question_5.py` to run a
different question. Run the mini-project entry point with:

```powershell
python .\mini_project\main.py
```

The files are placeholders at present, so they do not yet produce program
output.

## Mini-project

The mini-project is planned as a library management system. `book.py`,
`member.py`, and `library.py` are intended for the book, member, and library
classes, while `main.py` will serve as the program entry point. Its modules are
currently scaffolds and do not yet implement library operations.

## Structure

- `questions/`: files for questions 1 through 5.
- `mini_project/`: the entry point, domain modules, and project README.
