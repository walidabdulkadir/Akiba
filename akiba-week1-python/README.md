## 📚 What I Learned

During Week 1, I built a solid foundation in Python by working through 11 hands-on tasks. I learned how to declare and use variables of different data types — `str`, `int`, and `float` — and how to capture user input with `input()` and cast it to the correct type using `int()` and `float()`. I practiced arithmetic operators (`+`, `-`, `*`, `/`, `//`, `%`) across projects like the Rectangle Workshop, Temperature Station, and BMI Calculator. I used Python's `f-string` formatting to produce clean, structured output such as receipts, payslips, and student ID cards. I also explored conditional logic and built a mini Student Profile System that brings multiple concepts together. Beyond Python itself, I learned how to initialize a Git repository, commit changes, and push my work to GitHub for submission.
